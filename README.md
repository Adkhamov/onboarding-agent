# Стенд авто-онбординга ИИ-агента

Одностраничный стенд для сборки и тестирования ИИ-агента по ответам клиента на онбординге.

## Что делает

1. **Анкета клиента** — 7 базовых вопросов онбординга + дополнительные поля (имя агента, график, гео, цены, триггеры эскалации, языки, политика раскрытия ИИ, стоп-темы).
2. **Сборка промпта** — по ответам генерируется структурированный системный промпт с встроенными блоками:
   - человечная личность и тон;
   - знания о компании, FAQ, цены, КЭВ (целевое действие);
   - сбор данных клиента → функция `save_lead`;
   - фолбэк «не знаю» → функция `escalate_to_human`;
   - блок защиты от prompt-injection и попыток увести из роли.
3. **Тестовый чат** — выбор провайдера (Claude / OpenAI) и модели, ввод API-ключа, живой диалог. Вызовы функций отображаются плашками в чате (демо-режим, без реальных интеграций).

## Безопасность ключей

API-ключ вводится пользователем и хранится **только в localStorage вкладки**. Он никуда не отправляется, кроме API выбранного провайдера напрямую из браузера. В коде и репозитории секретов нет.

## Запуск локально

```bash
npm start
# http://localhost:3000
```

## Деплой

Статика отдаётся минимальным Node-сервером (`server.js`, без зависимостей) на порту `$PORT`. Разворачивается на Railway из этого репозитория.
